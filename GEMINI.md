# Tokencut for Gemini CLI

Tokencut provides adaptive brevity with structure-safe output.

## Activation

At session boot, include:
- `AGENTS.md`
- `.github/skills/tokencut/SKILL.md`
- `.github/skills/tokencut-memory/SKILL.md`

## Commands

- `/tokencut`
- `/tokencut auto`
- `/tokencut level <0-100>`
- `/tokencut profile <dev|learn|fast|auto>`
- `/tokencut memory <file>`

## Notes

For security warnings and destructive actions, switch to clarity-first wording and resume compression after the warning section.
